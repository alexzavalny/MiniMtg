# Магия: Учебная битва

Обучающая карточная игра в духе Magic: The Gathering против компьютера. Three.js, без сборки и без бэкенда.

## Документация

- [Как добавлять новую колоду](docs/adding-decks.md)

## Запуск

Открыть `index.html` в браузере (Chrome/Safari/Firefox). Работает прямо с диска (`file://`), интернет не нужен.

## Структура

- `js/cards.js` — карты и пять колод (Пламя, Лес, Свет, Вода, Могила)
- `js/engine.js` — правила: фазы хода, приоритет, стек, бой, state-based actions
- `js/ai.js` — компьютерный противник
- `js/cardart.js` — процедурная отрисовка карт на canvas
- `js/scene.js` — Three.js: стол, карты, анимации, частицы
- `js/ui.js`, `js/main.js` — HUD и связка движка с интерфейсом
- `test/sim.js` — симуляция AI против AI в node (`node test/sim.js 300`)
